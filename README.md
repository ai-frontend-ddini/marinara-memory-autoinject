# 기억 서재 자동 주입 (Marinara Engine 확장)

[기억 서재(marinara-memory-module)](https://github.com/tlsiddl/marinara-memory-module)를 **프리셋을 고치지 않고** 쓰기 위한 마리나라 개인 확장입니다.
기억 서재 본체와는 별개로 동작하는 비공식 보조 확장입니다.

## 하는 일

- **켜면**: 기억 서재에서 "이 방에서 기억 사용"이 켜진 **롤플레이 방**마다
  - 켜져 있던 채팅 요약(Chat Summary)을 모두 끄고
  - `{{기억}}` 한 줄짜리 요약 항목 "기억 서재 (자동 주입)"을 추가합니다.
- 마리나라는 요약 내용의 매크로도 치환하므로, 그 자리에 기억 서재의 기억이 들어갑니다.
  - 프리셋에 Chat Summary 마커가 있으면 → 마커 자리
  - 없으면 → 마리나라가 시스템 프롬프트 끝(채팅 기록 앞)에 자동으로 넣음
- 기억이 비어 있으면 요약 칸 자체가 빠집니다(빈 메시지 없음).
- 기억 서재에서 그 방의 기억을 끄면 그 방만 원래대로 되돌립니다.
- **끄거나 삭제하면**: 이 확장이 끈 요약만 다시 켜고, 추가한 항목을 지웁니다. 원래 꺼져 있던 요약은 그대로 둡니다.

## 필요한 것

- Marinara Engine
- 기억 서재 **서버 모듈** 설치·실행 (없으면 이 확장은 아무것도 하지 않습니다)

## 설치

**GitHub 확장 관리자 사용 시**: 이 저장소 주소를 등록하고 `manifest.json`을 선택합니다.

**직접 설치 시**: 이 저장소를 ZIP으로 받아(Code → Download ZIP) 마리나라 확장 설정에서 가져오고, **전체 페이지 접근**을 허용해 켭니다.

## 주의

- 롤플레이 방에서만 동작합니다. 콘보방은 마리나라가 요약을 다른 방식으로 처리해서 건너뜁니다.
- 고급 메모리(Advanced Memory)를 켠 방은 마리나라가 요약을 쓰지 않으므로 기억도 들어가지 않습니다.
- 프리셋에 `{{기억}}` 섹션을 이미 넣어 두었다면 두 번 들어가니 그 섹션은 빼 주세요.
- 요약에 `{{기억}}`을 직접 넣어 둔 방은 건너뜁니다.
- 무엇을 껐는지는 각 방 메타데이터(`memoryLibraryInject`)에 기록합니다. 기억 서재의 파일이나 프리셋은 건드리지 않습니다.
- 확장을 새 버전으로 바꾸면 마리나라가 잠시 확장을 끄기 때문에 한 번 되돌렸다가, 승인 후 다시 적용합니다.

## 확인 방법

기억 서재가 켜진 방의 채팅 요약 패널에 "기억 서재 (자동 주입)" 항목이 보이면 적용된 것입니다.
프롬프트 구성 미리보기의 Chat Summary 칸에서 실제 기억 내용을 확인할 수 있습니다.
