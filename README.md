# 기억 서재 자동 주입 (Marinara Engine 확장)

[기억 서재(marinara-memory-module)](https://github.com/tlsiddl/marinara-memory-module)를 쓸 때 프리셋마다 `{{기억}}` 섹션을 **직접 만들지 않아도 되게** 해 주는 마리나라 개인 확장입니다.
기억 서재 본체와는 별개로 동작하는 비공식 보조 확장입니다.

## 하는 일

**1. 프리셋에 Memory 섹션 자동 추가**

모든 프리셋에 `{{기억}}` 한 줄짜리 시스템 섹션 `📚 Memory`를 넣습니다. 위치는 아래 순서로 정합니다(꺼진 섹션·그룹은 없는 것으로 봅니다).

1. Chat Summary / Chat History 마커 중 먼저 나오는 것 **바로 위** — 기억 서재 README의 추천 위치
2. 두 마커가 모두 없으면 **앞쪽 시스템 프롬프트 묶음의 끝** — 어떤 모델에서도 시스템 지시로 읽히고, 프리필과 부딪히지 않는 자리
3. 첫 섹션부터 시스템이 아니면 **맨 위**

- 프리셋의 감싸기 형식이 XML이면 `<memory>`, 마크다운이면 `## Memory`로 감싸지고, '없음'이면 감싸지 않습니다. 기억 서재 출력이 `[Memory: …]` 안내로 시작해서 감싸지 않아도 모델이 구분할 수 있습니다.
- 기억 서재가 꺼진 방에서는 `{{기억}}`이 비어서 섹션이 통째로 빠집니다.
- 한 번 넣은 뒤 직접 옮긴 위치는 그대로 둡니다.
- 다른 섹션에 이미 `{{기억}}`을 넣어 둔 프리셋은 건드리지 않습니다.
- 마리나라 기본 제공 프리셋은 수정할 수 없어 건너뜁니다.

**2. 마리나라 채팅 요약 끄기 (선택, 기본 켬)**

기억 서재가 켜진 롤플레이 방의 마리나라 채팅 요약을 꺼서 지난 이야기가 두 번 들어가는 것을 막습니다. 무엇을 껐는지는 방 메타데이터(`memoryLibraryInject`)에 기록하고, 그 방의 기억을 끄거나 이 옵션·확장을 끄면 다시 켭니다.

**끄거나 삭제하면** 넣은 섹션을 모두 지우고 꺼 둔 요약을 되살립니다.

## 설정 화면

화면 오른쪽 아래 작은 버튼(줄 세 개 + 아래 화살표)을 누르면 열립니다. [확장 서랍](https://github.com/boricha417/marinara-extension-drawer)을 쓰면 서랍 안에 담깁니다.
현재 방 상태, 요약 끄기 옵션, 프리셋 처리 결과(추가·들어 있음·건너뜀 개수)를 볼 수 있고 **프리셋 다시 확인**으로 전체를 다시 맞출 수 있습니다.

## 자원 사용

주기적으로 서버를 훑지 않습니다. 마리나라를 열 때 한 번 전체를 맞춘 뒤에는 이럴 때만 움직입니다.

- 프리셋을 새로 만들거나 복제·가져오기 했을 때 → **새 프리셋에만** 섹션 추가
- 기억 서재에서 방의 기억을 켜거나 끌 때, 방을 옮길 때, 창으로 돌아올 때 → 방 상태 확인(작은 요청 한 번)

## 필요한 것

- Marinara Engine (2.5.1에서 확인)
- 기억 서재 **서버 모듈** 설치·실행 (없으면 요약 끄기는 하지 않습니다)

## 설치

**GitHub 확장 관리자 사용 시**: 이 저장소 주소를 등록하고 `manifest.json`을 선택합니다.

**직접 설치 시**: Code → Download ZIP으로 받아 마리나라 확장 설정에서 가져오고, **전체 페이지 접근**을 허용해 켭니다.

## 주의

- 콘보(대화) 모드 방은 프리셋을 쓰지 않아 해당되지 않습니다.
- 이미 프리셋에 `{{기억}}` 섹션을 손으로 만들어 두었다면 그 프리셋은 그대로 둡니다(중복 방지).
- 확장을 새 버전으로 바꾸면 마리나라가 잠시 확장을 끄기 때문에 한 번 되돌렸다가, 승인 후 다시 적용합니다.

## 확인 방법

마리나라 **프롬프트 구성** 미리보기에서 `📚 Memory` 칸이 채팅 요약·채팅 기록 바로 위에 보이면 들어간 것입니다.
